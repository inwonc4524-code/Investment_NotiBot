# Investment_NotiBot — 투자 테마 뉴스 알림 봇

보유 ETF와 관련된 테마의 **한국 · 미국 · 세계 뉴스**를 하루 4번 모아서 휴대폰(ntfy 앱)으로 보내줍니다.

| 테마 | 연결된 ETF |
|---|---|
| 🇺🇸 미국 S&P500 | TIGER 미국S&P500 |
| 🧬 나스닥 바이오 | TIGER 미국나스닥바이오 |
| 🔋 2차전지 | TIGER 2차전지테마 · KODEX 2차전지산업 · TIGER 2차전지소재Fn |
| ⚡ 전고체배터리·ESS | KODEX 전고체배터리ESS TOP2플러스 |
| 🏭 AI 전력 | ACE 코리아AI전력TOP10 |
| 🤖 로봇 | (관심 테마) |

## 알림 시간 (한국 시간)
- 07:40 — 미국장 마감 후
- 12:10 — 점심
- 17:10 — 한국장 마감 후
- 22:10 — 미국장 열리기 전

GitHub 사정에 따라 몇 분~수십 분 늦게 올 수 있습니다.

## 알림 모양
- **알림은 한 번만** 옵니다. 테마별 새 기사 수와 대표 제목이 보여요.
- 알림을 누르면 **뉴스 목록 페이지**가 열리고, 기사마다 눌러서 원문 사이트로 들어갈 수 있어요.
- 같은 소식을 다룬 기사들은 하나로 묶고, **보도한 언론사 수(🔥 언론 N곳)** 로 화제성 순위를 매깁니다.
  페이지 맨 위의 **전체 화제순 / 전체 최신순** 버튼, 또는 테마 제목 오른쪽의 **🔥 화제순 / 🕒 최신순** 버튼으로 정렬을 바꿀 수 있어요.
  (뉴스 사이트의 실제 조회수는 공개되지 않아서, 보도량을 화제성 기준으로 씁니다)
- 테마·지역별로 화제성 높은 소식을 최대 10개씩 모읍니다 (`MAX_PER_REGION`).
- 세계 뉴스 중 미국 뉴스와 같은 소식은 미국 쪽에 합칩니다.
- 한국어가 아닌 기사(영어·중국어 등)는 제목이 번역되고, **누르면 기사 전체가 한국어 번역본으로 열려요.** 카드 맨 아래 **원문 보기 ↗** 로 원래 기사도 볼 수 있어요.
- 이미 받은 기사는 다시 보내지 않습니다. 페이지에는 최근 3일치가 남아 있어요.

## 처음 설정
1. 휴대폰에 **ntfy** 앱 설치 → `+` 눌러서 나만 아는 주제 이름 구독 (예: `inwon-invest-7k3x9`)
2. 이 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: 위에서 정한 주제 이름
3. **Settings → Pages** → Build and deployment 의 **Source** 를 `GitHub Actions` 로 선택
   (안 켜도 작동은 하지만, 그때는 알림을 누르면 GitHub 화면의 `NEWS.md` 목록이 열려요)
4. **Actions** 탭 → `투자 테마 뉴스 알림 봇` → **Run workflow** 로 한 번 실행해서 알림이 오는지 확인

## 테마 · 검색어 바꾸기
`news_bot.py` 맨 위의 `THEMES` 부분만 고치면 됩니다.
- `kr` = 한국 뉴스 검색어, `en` = 미국·세계 뉴스 검색어
- ETF를 새로 사면 테마를 하나 추가하면 됩니다.
