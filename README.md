### 자동 추가 (인용·공동 보도 기준)
목록에 없는 언론사라도, 최근 14일 동안 **보도한 소식이 10개 이상**이고, 그중 **절반 이상(6개 이상)을 주요 언론사 2곳 이상도 함께 보도**했으며, **주요 언론사보다 먼저 보도한 소식이 3개 이상**이면 믿을 만한 곳으로 자동 추가됩니다. (남의 기사를 받아 쓰기만 하는 곳은 먼저 보도하는 일이 거의 없어서 걸러져요. 증권사 자체 콘텐츠도 제외)

자동 추가된 곳은 목록 페이지 맨 아래에서 확인할 수 있어요.

## 목록 페이지 보는 법
- 위쪽 **탭**(🚨 미국 속보 · 테마별)을 누르면 그 탭의 뉴스만 보여요. 마지막으로 본 탭을 기억해요.
- 새 뉴스가 들어온 탭에는 **빨간 점(레드닷)** 이 뜨고, 그 탭에 들어가면 사라져요. 새 기사에는 **NEW** 표시.
- 탭 아래 **🔥 화제순 / 🕒 최신순**, **국가(전체 · 한국 · 미국 · 중국 · 대만 · 홍콩 · 일본 · 싱가포르 · 세계)** 버튼으로 골라 볼 수 있어요.
- 테마마다 상위 8개를 먼저 보여주고 **더보기**로 20개씩 더 펼쳐요.

## 기사 요약 보기
- 목록에서 기사를 누르면 바로 원문으로 가지 않고, 아래에서 **한국어 요약 창**이 올라와요. 요약을 읽고 **원문 보기 ↗** 또는 **닫기**를 고르면 돼요.
- 요약은 언론사가 직접 쓴 기사 소개 문구(없으면 본문 앞부분 2~3문장)를 가져와 한국어로 번역한 거예요.
- 일부 사이트(블룸버그·로이터 등)는 자동 접속을 막아서 요약이 없을 수 있어요. 그래도 원문 보기는 됩니다.
- **외국어 기사**에는 **✦ 원문 + Gemini 요약 / ✦ 원문 + Gemini 쉬운 번역** 버튼이 있어요. 누르면 요청 문장이 **복사**되고 원문 기사가 열려요. 원문을 **크롬**에서 연 상태로 **측면 버튼을 길게 눌러 Gemini** → **「이 페이지에 관해 질문하기」** → 붙여넣기 → 보내기 하면, Gemini가 **기사 전체**를 읽고 한국어로 요약·번역해 줘요. (「화면에 대해 질문하기」는 화면에 보이는 부분만 읽으니 주의) (Gemini가 사이트에 직접 접속하지 않아서 접근 차단을 피할 수 있어요)
- 삼성 인터넷으로 열면 **브라우징 어시스트**(Galaxy AI)의 요약·번역 기능도 쓸 수 있어요.

## 알림 모양
- **알림은 한 번만** 옵니다. 테마별 새 기사 수와 대표 제목이 보여요.
- 알림을 누르면 **뉴스 목록 페이지**가 열리고, 기사마다 눌러서 원문 사이트로 들어갈 수 있어요.
- 같은 소식을 다룬 기사들은 하나로 묶고, **보도한 언론사 수(🔥 언론 N곳)** 로 화제성 순위를 매깁니다.
  페이지 맨 위의 **전체 화제순 / 전체 최신순** 버튼, 또는 테마 제목 옆의 **🔥 화제순 / 🕒 최신순** 버튼으로 정렬을 바꿀 수 있어요.
- **국가별 보기**: 맨 위의 **전체 · 한국 · 미국 · 세계 · 홍콩 · 대만** 버튼(전체 테마), 또는 테마 제목 옆의 국가 선택(그 테마만)으로 골라 볼 수 있어요.
  (뉴스 사이트의 실제 조회수는 공개되지 않아서, 보도량을 화제성 기준으로 씁니다)
- 한 번 실행할 때 테마·지역별로 화제성 높은 소식을 최대 6개씩 모읍니다 (`MAX_PER_REGION`).
- 목록 페이지는 테마마다 **상위 8개**만 먼저 보여주고, **더보기**를 누를 때마다 20개씩 더 펼쳐져요 (`SHOW_PER_THEME`).
- 세계 뉴스 중 미국 뉴스와 같은 소식은 미국 쪽에, 대만 뉴스 중 홍콩 뉴스와 같은 소식은 홍콩 쪽에 합칩니다.
- 한국어가 아닌 기사(영어·중국어 등)는 제목이 한국어로 번역되고, 아래에 원문 제목도 작게 보여요. 누르면 원문 기사로 이동해요.
- 이미 받은 기사는 다시 보내지 않습니다. 페이지에는 최근 3일치가 남아 있어요.

## 🚨 미국 속보 · 🌏 해외 속보
- **🚨 미국 속보**: 큰 소식이면 휴대폰으로 바로 알림 + 탭에 쌓임
- **🌏 해외 속보**: 한국·중국·대만·홍콩·일본·싱가포르·세계에서 여러 언론이 동시에 보도했거나, 언론사가 제목에 속보([속보]·速報·快訊 등)라고 단 소식. 기본은 **탭에만 쌓이고 알림은 안 옴** (`GLOBAL_BREAKING_PUSH = True` 로 바꾸면 알림도 옴)

- 평일(한국 시간 월 09시 ~ 토 10시)에 **약 12분마다** 확인합니다.
  (GitHub 의 예약 실행은 자주 누락돼서, 한 번 시작하면 12분 간격으로 5번 확인하고 끝날 때 다음 작업을 직접 이어서 시작해요. 1시간마다 예약 실행은 끊겼을 때 다시 잇는 예비용)
- 최근 90분 안에 **여러 언론(3곳 이상)이 동시에 보도한 소식**, 또는 제목에 BREAKING 같은 표시가 있는 소식이면 **바로 알림**을 보내요 (한 번에 최대 3개).
- 알림을 누르면 기사 원문으로 바로 이동하고, 목록 페이지의 **🚨 미국 속보** 탭에도 바로 반영돼요.
- 기준은 `news_bot.py` 의 `BREAKING_MIN_SOURCES`(언론 수), `BREAKING_WORDS`(검색어)로 조절할 수 있어요.

## 처음 설정
1. 휴대폰에 **ntfy** 앱 설치 → `+` 눌러서 나만 아는 주제 이름 구독 (예: `inwon-invest-7k3x9`)
2. 이 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: 위에서 정한 주제 이름
3. **Settings → Pages** → Build and deployment 의 **Source** 를 `GitHub Actions` 로 선택
   (안 켜도 작동은 하지만, 그때는 알림을 누르면 GitHub 화면의 `NEWS.md` 목록이 열려요)
4. **Actions** 탭 → `투자 테마 뉴스 알림 봇` → **Run workflow** 로 한 번 실행해서 알림이 오는지 확인
